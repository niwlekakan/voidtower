# VoidTower central-hub backlog (prioritized)

Goal: VoidTower becomes the single management surface for the whole homelab: inventory,
hostnames, TLS, identity, logs, metrics, AI stack, git repos, dev and prod.

Priority order. P0 unblocks the rest; P1 makes it trustworthy; P2 makes it the hub.

## P0 - visibility (do first)

0. **Route triage (config only, do before code)**
   - `remote.heimdallr.cv` has DNS but no NPM host; LXC 102 is 192.168.50.194 running
     hbbs/hbbr plus `rustdesk-api` on 21114. Decide whether the hostname serves the
     API/console only (clients stay on 21114 direct) before adding a proxy host.
   - `docker.heimdallr.cv` -> `dockge:5001` does not exist on LXC 101; find the real Dockge.
   - `comfyui.heimdallr.cv` -> 192.168.50.100:8188 has no listener; ComfyUI binds loopback
     on berserkr. Either bind it to the LAN or remove the route.

1. **NPM adapter + host dashboard** (spec: `npm-adapter-and-host-dashboard.md`)
   - additive migration: `url`, `hostname`, `kind`, `hidden` on `deployed_apps`
   - `networking/npm.rs`: list hosts, list certs, sync; writes behind capability flag
   - dashboard table: hostname, upstream, TLS days left, auth mode, linked app, https link
   - acceptance: every enabled hostname listed with working link; expired cert is red

2. **App vault correctness**
   - render `url` when present, plain hostname otherwise
   - `hidden=1` for infrastructure guests, excluded from vault but visible in inventories
   - `kind` badge: docker vs proxmox vs external

3. **RustDesk route and visibility**
   - fix `remote.heimdallr.cv` upstream to LXC 102
   - document that hbbs/hbbr (21114-21119) cannot do OIDC: clients are key-authenticated
   - if a web console exists, gate it with the Authentik outpost like the other hosts
   - do not put the relay behind Authentik; it would break client connectivity

## P1 - trust and operations

4. **Reports**: weekly JSON+markdown report generated by the backend (uptime, cert expiry,
   disk growth, container drift, failed backups), stored and downloadable.
5. **Certificate expiry watch**: warn at 21/14/7 days, fail closed on <7.
6. **Metrics + logs**: Prometheus node/cadvisor exporters on 101, Loki or vector for logs,
   Grafana as a catalog app behind Authentik. VoidTower links out and embeds panels.
7. **Backup status**: surface Proxmox backup job results per guest, last success per VMID.

## P2 - the hub itself

8. **Network device inventory**: nmap/ARP sweep + manual labels for router, PCs, phones,
   HTPC, printers; devices table with last-seen and hostname mapping.
9. **AI stack page**: Hermes profiles, cron jobs, supervisor state, OmniRouter meters,
   Ollama models, ComfyUI status, harness runs. Read-only first.
10. **Git repos**: local bare remotes per project, commit graph, dirty-state badge,
    dev/prod environment pairs, deploy history in VoidTower.
11. **Dev/prod parity**: environment definitions (dev VM 100, prod LXC 101) with
    promote/rollback actions, gated by approval.

## Non-goals

- Replacing NPM with VoidTower's own nginx-proxy. NPM owns TLS and has 16 working hosts.
- Replacing Authentik. VoidTower consumes identity, it does not become the IdP.
- A separate dashboard service. Duplicates auth, storage and inventory.
